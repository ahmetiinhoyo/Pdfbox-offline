## 🤔 Почему офлайн PDF-инструмент? (Приватность прежде всего)

Большинство «бесплатных» онлайн PDF-сервисов (объединение, разделение, сжатие):
- ❌ Загружают ваши документы на **свои серверы** — часто за границу, часто с хранением на несколько дней
- ❌ Полны рекламы, баннеров о cookies и скриптов слежки
- ❌ Вводят лимиты на размер файла и дневные квоты, если не платить
- ❌ Требуют регистрации, e-mail или даже банковской карты

**PDFBox Offline** — полная противоположность:
- ✅ **100% офлайн** — вся обработка PDF происходит локально в вашем браузере; файлы не покидают устройство
- ✅ **Приватность по умолчанию** — безопасно для договоров, документов, счетов, медицинских и юридических записей
- ✅ **Без рекламы, слежки и аналитики** — нечего даже отключать
- ✅ **Без ограничения размера** — предел только у вашего устройства
- ✅ **Без регистрации** — открыли страницу и работайте
- ✅ **Многоязычный** — English / Türkçe / Русский
- ✅ **Открытый код (MIT)** — каждую строку можно проверить на GitHub

## 📖 Как использовать — объединяйте, разделяйте, конвертируйте и очищайте PDF без загрузки

### 📎 Объединить PDF-файлы офлайн
1. Нажмите на **Объединить PDF** или перетащите файлы
2. Выберите несколько PDF — они добавляются в список с количеством страниц
3. Удалите ненужные кнопкой корзины
4. *(Опционально)* Отметьте **«Очистить метаданные»** — из результата будут удалены автор, программа, заголовок, ключевые слова и т.д.
5. Нажмите **«Объединить и скачать»** → скачается `merged.pdf` (или `merged-clean.pdf`)

### ✂️ Разделить PDF офлайн
1. Нажмите на **Разделить PDF**, выберите файл
2. В поле **Диапазон страниц** введите:
   - `1-3` → страницы 1, 2, 3
   - `1, 3, 5` → только 1, 3, 5
   - `1-2, 5, 7-9` → смешанные диапазоны
   - Пусто → все страницы
3. *(Опционально)* Отметьте **«Очистить метаданные»**
4. Нажмите **«Разделить и скачать»** → скачается `split.pdf` (или `split-clean.pdf`)

### 🖼️ Конвертировать изображения JPG/PNG/WEBP в PDF
1. Нажмите на **Изображения в PDF** или перетащите картинки
   - Поддерживаются **JPG, PNG, WEBP, GIF, BMP, AVIF** — HEIC-файлы помечаются и пропускаются
   - У каждого изображения миниатюра в списке; меняйте порядок кнопками **вверх/вниз**
2. Выберите настройки:
   - **Размер страницы:** A4 / Letter / По изображению (ограничение по длинной стороне, пропорции сохранены)
   - **Ориентация:** Авто / Книжная / Альбомная
   - **Поля:** Нет / Маленькие / Средние
   - **Качество:** Экран (минимальный размер) / Высокое (баланс) / Оригинал (лучшее качество)
3. *(Опционально)* Отметьте **«Очистить метаданные»**
4. Нажмите **«Создать PDF и скачать»** → скачается `images-to-pdf.pdf` (или `images-to-pdf-clean.pdf`) · **Просмотр** покажет результат на весь экран

> Примечание: Каждое изображение занимает одну страницу — вписывается и центрируется; страниц столько же, сколько изображений.

### 🔄 Редактор страниц (удаление / порядок)
1. Перейдите на вкладку **Редактор страниц**, выберите PDF — все страницы появятся сеткой миниатюр
2. Кнопками **◀ / ▶** меняйте порядок страниц (на первой/последней странице крайняя кнопка заблокирована), **✕** — удалить
3. Счётчик показывает, сколько страниц останется; **«Сброс»** вернёт исходный порядок
4. *(Опционально)* Отметьте **«Очистить метаданные»**
5. Нажмите **«Создать PDF и скачать»** → скачается `edited.pdf` (или `edited-clean.pdf`) · **Просмотр** покажет результат на весь экран

### 🖼️ Просмотр всех страниц перед объединением
1. Добавьте 2+ файла в список объединения
2. Нажмите **«Просмотр всех»**
3. Страницы каждого PDF появятся в одной галерее, сгруппированные под заголовками файлов — в порядке объединения
4. Нажмите на страницу → откроется **полноэкранный просмотр**
5. Листайте стрелками или кнопками — просмотр **перетекает между файлами** (конец файла 1 → начало файла 2)
6. Страницы рендерятся в высоком разрешении — текст чёткий
7. Приближайте и отдаляйте кнопками **+ / −**, через **Ctrl + колесо мыши** или клавишами **+ / −**; клавиша **0** (или кнопка «по размеру») возвращает страницу по размеру экрана

### 🧹 Удалить скрытые метаданные PDF (автор, производитель, ключевые слова)
PDF содержат скрытую информацию: имя автора, программу, даты, заголовок, ключевые слова. Очистить можно 4 способами:

1. **Кнопка «Очистить метаданные» слева сверху** → откроется отдельный инструмент:
   - Выберите PDF → увидите, **какие метаданные найдены** (автор, заголовок, тема, создатель, производитель, ключевые слова)
   - Просмотрите, затем нажмите **«Очистить и скачать»** → скачается `cleaned.pdf`
2. **Объединение + галочка** → объединить и очистить за один шаг
3. **Разделение + галочка** → разделить и очистить за один шаг
4. **Изображения в PDF + галочка** → конвертировать с очисткой → `images-to-pdf-clean.pdf`

> Примечание: Даты создания/изменения документа **сохраняются** — удаляются только идентификационные поля.

### 🌍 Смена языка
Нажмите **TR / EN / RU** в правом верхнем углу. Выбор сохраняется.

### 🎨 Тема и акцентный цвет
- Переключайте **тёмную / светлую** тему кнопкой луны/солнца
- Выберите один из **4 акцентных цветов** (синий, зелёный, оранжевый, розовый) в выпадающем меню — выбранный образец отмечен

## ❓ FAQ — Офлайн и приватность

**Мои файлы куда-то загружаются?**
Нет. У PDFBox Offline **нет бэкенда**. Каждая операция — объединение, разделение, конвертация изображений, очистка метаданных — выполняется локально в вашем браузере. Проверьте сами: откройте DevTools → вкладку Network, загрузите файл и понаблюдайте — ничего никуда не отправляется.

**Работает ли он без интернета?**
Сама страница подаётся с Vercel (с зеркалом на GitHub Pages), поэтому один раз нужен интернет для загрузки. После этого **вся обработка происходит офлайн на вашем устройстве** — документы никогда не передаются во время работы.

**PDFBox Offline действительно бесплатный?**
Да — полностью бесплатный, без рекламы, с открытым кодом по [лицензии MIT](LICENSE).

**Какие типы файлов поддерживаются?**
PDF — для объединения, разделения и работы с метаданными; изображения **JPG, PNG, WEBP, GIF, BMP и AVIF** — для конвертера в PDF (файлы HEIC обнаруживаются и помечаются).

**Безопасно ли для чувствительных документов (договоры, документы, счета, медицинские записи)?**
Именно для этого он и создан: файлы не покидают устройство — нечему утекать, нечего логировать, нечего взламывать.

**Я случайно нажал кнопку «назад» — работа потеряется?**
Нет. Пока открыто окно просмотра, кнопка «назад» **сначала закрывает просмотр** — вас не выбрасывает из приложения. А пока загружен хотя бы один файл, страница запрашивает у браузера **подтверждение перед выходом** (кнопка «назад», закрытие вкладки, перезагрузка). Учтите: сама страница файлы не хранит — если подтвердить выход, загруженные файлы исчезнут. Это обратная сторона того, что всё обрабатывается локально и ничего не загружается на сервер.

## 🛠️ Технологии

- **[Vite](https://vitejs.dev/)** — сборка
- **[pdf-lib](https://pdf-lib.js.org/)** — работа с PDF (объединение, разделение, метаданные, вставка изображений)
- **Canvas API** — масштабирование изображений и конвертация в JPEG (изображения в PDF)
- **[pdfjs-dist](https://mozilla.github.io/pdf.js/)** — рендеринг PDF (просмотр)
- **Vanilla JS** — без фреймворков, быстро и легко
- **Inline SVG спрайт иконок** — без эмодзи и иконочных шрифтов
- **Vercel** — основной хостинг (статический деплой Vite, бесплатный домен `*.vercel.app`)
- **GitHub Actions** — CI/CD (автосборка + деплой)
- **GitHub Pages** — бесплатное зеркало

## Структура проекта (модульная — каждый исходный файл ≤ 200 строк)

Код разбит на модули с жёстким лимитом **200 строк на исходный файл** — чтобы проект было легко
проверять как открытый исходный код. Правило контролируется через `npm run check:lines`
(README и `llms.txt` в это правило не входят).

| Путь | Содержимое |
|---|---|
| `index.html` | Каркас HTML: верхняя панель, карточки, модальные окна, SVG спрайт иконок |
| `src/main.js` | Точка входа (bootstrap) |
| `src/core/` | Инфраструктура: состояние, DOM-помощники, тосты, тема, язык, метаданные |
| `src/features/` | Функции: `merge.js`, `split.js`, `meta-tool.js`, `images/` (5 модулей), `pages/` (4 модуля), `preview/` (сетка + просмотр) |
| `src/ui/` | HTML-фрагменты карточек (напр. `images-card.html`) — внедряются без изменения `index.html` |
| `src/locales/` | Переводы `tr.js`, `en.js`, `ru.js` |
| `src/styles/` | 19 модулей стилей (тема, карточки, кнопки, модальные окна, просмотр, карточка изображений, вкладки инструментов, редактор страниц, мобильные) |
| `src/style.css` | Точка входа стилей — только список `@import` |
| `scripts/check-lines.mjs` | Проверка правила 200 строк |

Добавить функцию = один модуль в `src/features/` + ключи во всех трёх файлах `src/locales/`.

## 🌐 Деплой и хостинг

Приложение — статический сайт на Vite, поэтому **один и тот же commit публикуется на двух платформах**:

| Платформа | URL | Базовый путь | Настройка |
|---|---|---|---|
| **Vercel** (основная) | https://pdfbox-offline.vercel.app/ | `/` | Пресет `Vite`, сборка `npm run build`, вывод `dist` — переменные окружения не нужны |
| **GitHub Pages** (зеркало) | https://ahmetiinhoyo.github.io/Pdfbox-offline/ | `/Pdfbox-offline/` | `.github/workflows/static.yml` собирает и публикует `dist` при каждом push в `main` |

`vite.config.js` выбирает базовый путь автоматически:

```js
base: process.env.VERCEL ? '/' : '/Pdfbox-offline/',
```

Vercel подставляет `VERCEL=1` во время сборки, поэтому ресурсы берутся из `/`; в GitHub Actions этой переменной нет, поэтому префикс `/Pdfbox-offline/` сохраняется. Ручная настройка не требуется ни там, ни там.
