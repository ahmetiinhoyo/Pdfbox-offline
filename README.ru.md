
# 📦 PDFBox Offline

> Офлайн-инструмент для PDF — объединение, разделение, очистка. Без загрузки. Без рекламы. Без слежки.

**🌐 Демо:** [https://ahmetiinhoyo.github.io/Pdfbox-offline/](https://ahmetiinhoyo.github.io/Pdfbox-offline/)

**Языки:** [🇬🇧 English](README.md) · [🇹🇷 Türkçe](README.tr.md) · 🇷🇺 Русский

---

## Почему PDFBox?

Большинство онлайн-инструментов:
- ❌ Загружают ваши файлы на **свои серверы**
- ❌ Полны рекламы и трекеров
- ❌ Ограничивают размер файла
- ❌ Требуют регистрации

**PDFBox Offline:**
- ✅ **100% офлайн** — файл не покидает устройство
- ✅ **Без рекламы и слежки**
- ✅ **Без ограничений** на размер
- ✅ **Без регистрации**
- ✅ **Многоязычный** — English / Türkçe / Русский
- ✅ **Открытый исходный код**

## 🚀 Использование

Откройте: [https://ahmetiinhoyo.github.io/Pdfbox-offline/](https://ahmetiinhoyo.github.io/Pdfbox-offline/)

### 📎 Объединить PDF
1. Нажмите на **Объединить PDF**
2. Выберите несколько PDF (по одному, они накапливаются)
3. Удалите ненужные кнопкой **✕**
4. Нажмите **"Объединить и скачать"**
5. Файл `merged.pdf` скачается 🎉

### ✂️ Разделить PDF
1. Нажмите на **Разделить PDF**, выберите файл
2. В поле **Диапазон страниц** введите:
   - `1-3` → страницы 1, 2, 3
   - `1, 3, 5` → только 1, 3, 5
   - `1-2, 5, 7-9` → смешанные
   - Пусто → все страницы
3. Нажмите **"Разделить и скачать"**
4. Файл `split.pdf` скачается 🎉

### 🌍 Смена языка
Нажмите **TR / ENG / RU** в правом верхнем углу. Выбор сохраняется.

**Важно:** Файлы **никогда** не отправляются на сервер. Всё работает в браузере (WebAssembly).
