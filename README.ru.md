## 🤔 Почему PDFBox?

Большинство онлайн-инструментов:
- ❌ Загружают ваши файлы на **свои серверы**
- ❌ Полны рекламы и трекеров
- ❌ Ограничивают размер файла
- ❌ Требуют регистрации

**PDFBox Offline:**
- ✅ **100% офлайн** — файл не покидает устройство
- ✅ **Без рекламы и слежки**
- ✅ **Без ограничений** на размер
- ✅ **Без регистрации**
- ✅ **Многоязычный** — English / Türkçe / Русский
- ✅ **Открытый исходный код**

## 📖 Использование

### 📎 Объединить PDF
1. Нажмите на **Объединить PDF** или перетащите файлы
2. Выберите несколько PDF — они добавляются в список с количеством страниц
3. Удалите ненужные кнопкой корзины
4. *(Опционально)* Отметьте **«Очистить метаданные»** — из результата будут удалены автор, программа, заголовок, ключевые слова и т.д.
5. Нажмите **«Объединить и скачать»** → скачается `birlestirilmis.pdf` (или `cleanmeta-birlestirilmis.pdf`)

### ✂️ Разделить PDF
1. Нажмите на **Разделить PDF**, выберите файл
2. В поле **Диапазон страниц** введите:
   - `1-3` → страницы 1, 2, 3
   - `1, 3, 5` → только 1, 3, 5
   - `1-2, 5, 7-9` → смешанные диапазоны
   - Пусто → все страницы
3. *(Опционально)* Отметьте **«Очистить метаданные»**
4. Нажмите **«Разделить и скачать»** → скачается `bolunmus.pdf` (или `cleanmeta-bolunmus.pdf`)

### 🖼️ Изображения в PDF
1. Нажмите на **Изображения в PDF** или перетащите картинки
   - Поддерживаются **JPG, PNG, WEBP, GIF, BMP, AVIF** — HEIC-файлы помечаются и пропускаются
   - У каждого изображения миниатюра в списке; меняйте порядок кнопками **вверх/вниз**
2. Выберите настройки:
   - **Размер страницы:** A4 / Letter / По изображению (ограничение по длинной стороне, пропорции сохранены)
   - **Ориентация:** Авто / Книжная / Альбомная
   - **Поля:** Нет / Маленькие / Средние
   - **Качество:** Экран (минимальный размер) / Высокое (баланс) / Оригинал (лучшее качество)
3. *(Опционально)* Отметьте **«Очистить метаданные»**
4. Нажмите **«Создать PDF и скачать»** → скачается `gorselden-pdf.pdf` (или `cleanmeta-gorselden.pdf`) · **Просмотр** покажет результат на весь экран

> Примечание: Каждое изображение занимает одну страницу — вписывается и центрируется; страниц столько же, сколько изображений.

### 🖼️ Просмотр всех
1. Добавьте 2+ файла в список объединения
2. Нажмите **«Просмотр всех»**
3. Страницы каждого PDF появятся в одной галерее, сгруппированные под заголовками файлов — в порядке объединения
4. Нажмите на страницу → откроется **полноэкранный просмотр**
5. Листайте стрелками или кнопками — просмотр **перетекает между файлами** (конец файла 1 → начало файла 2)
6. Страницы рендерятся в высоком разрешении — текст чёткий

### 🧹 Очистить метаданные
PDF содержат скрытую информацию: имя автора, программу, даты, заголовок, ключевые слова. Очистить можно 4 способами:

1. **Кнопка «Очистить метаданные» слева сверху** → откроется отдельный инструмент:
   - Выберите PDF → увидите, **какие метаданные найдены** (автор, заголовок, тема, создатель, производитель, ключевые слова)
   - Просмотрите, затем нажмите **«Очистить и скачать»** → скачается `cleanmeta.pdf`
2. **Объединение + галочка** → объединить и очистить за один шаг
3. **Разделение + галочка** → разделить и очистить за один шаг
4. **Изображения в PDF + галочка** → конвертировать с очисткой → `cleanmeta-gorselden.pdf`

> Примечание: Даты создания/изменения документа **сохраняются** — удаляются только идентификационные поля.

### 🌍 Смена языка
Нажмите **TR / EN / RU** в правом верхнем углу. Выбор сохраняется.

### 🎨 Тема и акцентный цвет
- Переключайте **тёмную / светлую** тему кнопкой луны/солнца
- Выберите один из **4 акцентных цветов** (синий, зелёный, оранжевый, розовый) в выпадающем меню — выбранный образец отмечен

## 🛠️ Технологии

- **[Vite](https://vitejs.dev/)** — сборка
- **[pdf-lib](https://pdf-lib.js.org/)** — работа с PDF (объединение, разделение, метаданные, вставка изображений)
- **Canvas API** — масштабирование изображений и конвертация в JPEG (изображения в PDF)
- **[pdfjs-dist](https://mozilla.github.io/pdf.js/)** — рендеринг PDF (просмотр)
- **Vanilla JS** — без фреймворков, быстро и легко
- **Inline SVG спрайт иконок** — без эмодзи и иконочных шрифтов
- **GitHub Actions** — CI/CD (автосборка + деплой)
- **GitHub Pages** — бесплатный хостинг

## Структура проекта (модульная — каждый исходный файл ≤ 200 строк)

Код разбит на модули с жёстким лимитом **200 строк на исходный файл** — чтобы проект было легко
проверять как открытый исходный код. Правило контролируется через `npm run check:lines`
(README и `llms.txt` в это правило не входят).

| Путь | Содержимое |
|---|---|
| `index.html` | Каркас HTML: верхняя панель, карточки, модальные окна, SVG спрайт иконок |
| `src/main.js` | Точка входа (bootstrap) |
| `src/core/` | Инфраструктура: состояние, DOM-помощники, тосты, тема, язык, метаданные |
| `src/features/` | Функции: `merge.js`, `split.js`, `meta-tool.js`, `images/` (5 модулей), `preview/` (сетка + просмотр) |
| `src/ui/` | HTML-фрагменты карточек (напр. `images-card.html`) — внедряются без изменения `index.html` |
| `src/locales/` | Переводы `tr.js`, `en.js`, `ru.js` |
| `src/styles/` | 17 модулей стилей (тема, карточки, кнопки, модальные окна, просмотр, карточка изображений, мобильные) |
| `src/style.css` | Точка входа стилей — только список `@import` |
| `scripts/check-lines.mjs` | Проверка правила 200 строк |

Добавить функцию = один модуль в `src/features/` + ключи во всех трёх файлах `src/locales/`.
